# 부스 QR 방문 카운터

부스마다 전용 QR을 만들고, 방문객이 휴대폰으로 QR을 찍으면 그 부스 방문자 수가 실시간으로 올라가는 사이트입니다.
설치할 라이브러리가 없고 Node.js(18 이상)만 있으면 실행됩니다.

## 실행

```bash
ADMIN_PASSWORD=원하는비밀번호 node server.js
```

브라우저에서 `http://localhost:3000/admin`에 접속한 뒤 비밀번호로 로그인합니다.

## 사용 순서

1. **부스 추가**: 관리자 화면에서 부스 이름 입력 (줄바꿈으로 여러 개 한 번에)
2. **QR 인쇄**: "QR 전체 인쇄" → A4로 인쇄해서 각 부스에 부착
3. **방문객**: 휴대폰 카메라로 QR 찍기 → "방문이 기록되었어요" 화면 + 몇 개 부스를 돌았는지 표시
4. **현황 확인**: 관리자 화면이 3초마다 자동 갱신. CSV로 내려받아 엑셀에서 열 수 있음

## 집계 방식

- **방문자**: 같은 휴대폰이 같은 부스를 여러 번 찍어도 1명 (브라우저 쿠키로 구분)
- **스캔**: 찍은 전체 횟수 (10초 안의 중복 새로고침은 제외)

## 인터넷에 올리기 (행사 때 필수)

방문객 휴대폰에서 접속하려면 인터넷 주소가 있어야 합니다.

- **Render / Railway / Fly.io** 등: 이 폴더를 GitHub에 올리고 Node 앱으로 배포, 시작 명령 `node server.js`
  - 환경변수 `ADMIN_PASSWORD` 설정
  - 데이터가 지워지지 않도록 **영구 디스크(Persistent Disk/Volume)** 를 연결하고 `DATA_FILE=/디스크경로/data.json` 지정
- **같은 와이파이에서 노트북으로 운영**: 노트북에서 `PUBLIC_URL=http://노트북IP:3000` 으로 실행

⚠ QR 안에는 사이트 주소가 들어갑니다. **최종 주소로 접속한 상태에서 QR을 인쇄**하세요
(또는 `PUBLIC_URL=https://내도메인` 지정).

## 환경변수

| 이름 | 설명 | 기본값 |
|---|---|---|
| `ADMIN_PASSWORD` | 관리자 비밀번호 | `admin1234` (꼭 바꾸세요) |
| `PORT` | 포트 | `3000` |
| `DATA_FILE` | 데이터 저장 파일 | `./data/data.json` |
| `PUBLIC_URL` | QR에 넣을 사이트 주소 | 접속한 주소 자동 사용 |
